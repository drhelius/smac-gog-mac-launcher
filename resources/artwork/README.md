# SMAC Launcher artwork

`smac-launcher-square.png` is the app-icon source: opaque, borderless square artwork. The build exports macOS sizes and compiles the AppIcon asset catalog, letting macOS apply its own shape. This avoids a bordered tile being placed inside another system icon tile. `smac-launcher-icon.png` is retained as the earlier artwork source.

Prompt:

> macOS application icon for SMAC Launcher: a richly rendered alien planet with dark ocean blue, jade-green land and a restrained luminous atmospheric rim, with two small warm stars suggesting Alpha Centauri. A refined cinematic science-fiction miniature, strong simple silhouette, premium macOS icon craftsmanship, legible at small Dock sizes. The planet is the dominant subject inside a deep midnight rounded-square tile, subtly beveled with elegant lighting. Standard macOS icon margins, genuinely transparent outside the rounded tile. No words, letters, numerals, rockets, game logos, badges, UI mockups or watermark.

This is original project artwork, not extracted from the game.

Square-version edit prompt, using the built-in image generation tool:

> Preserve the existing planet, two warm stars, colors, lighting, proportions and composition. Convert the rounded tile into full-bleed opaque square artwork: extend its dark blue space background to all four square edges and corners, remove the outer rounded frame/bevel and transparent margins. No white background, border, inset tile, padding or baked-in rounded corners. The operating system applies its own mask.
